# Support file attachments as read-only snapshots

Carrent supports one or more mixed Image and UTF-8 File Attachments per message. Every attached file is copied into Carrent's app-data attachment store as a stable snapshot, so history stays reproducible and raw app-data paths stay out of visible messages and the App State Snapshot. Agent Core can read only the exact attachment paths present on the current `ChatTurnRequest`; attachments do not grant writes, sibling-file reads, or directory-wide access. Folders remain additional local path contexts, not attachments. Binary non-image formats stay unsupported until Agent Core has a reliable binary/document input path. This decision extends ADR 0003's Carrent-owned snapshot model to text files and supersedes only the single-file cardinality wording in ADR 0007.
