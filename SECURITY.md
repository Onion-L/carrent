# Security Policy

## Supported Versions

Only the latest release of Carrent receives security fixes. Older versions are
not supported — if you are running anything other than the newest release,
please upgrade.

| Version              | Supported |
| -------------------- | --------- |
| Latest release       | Yes       |
| Older releases       | No        |
| Beta / nightly builds | No       |

## Beta and Nightly Builds

Beta and nightly builds are test versions. They may contain unfinished
features, known issues, and unpatched vulnerabilities. Do not use them with
sensitive data or in environments where security matters — use the latest
stable release instead.

## Reporting a Vulnerability

Please report security issues by opening an issue at
<https://github.com/Onion-L/carrent/issues>.
