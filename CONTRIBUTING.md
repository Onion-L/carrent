# Contributing to Carrent

Thank you for your interest in Carrent.

Carrent is a small, maintainer-led project. To remain responsible for its
quality and long-term maintenance, I need to keep outside contributions very
limited in scope.

Small, focused changes are welcome, such as minor bug fixes, documentation
corrections, or other changes that are straightforward to review. Please do
not submit pull requests for large features, broad improvements, major
refactors, or architectural changes. I do not currently have the capacity to
review and maintain changes of that size with the care they deserve.

If you have an idea for a substantial feature that you believe would be
valuable, you are welcome to fork the project and implement it in your own
version. Please understand that a large pull request may be declined even when
the idea and implementation are good.

When in doubt, please open an issue to discuss the scope before investing time
in a pull request.
