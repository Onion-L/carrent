# Thread State Regressions

Carrent has several confirmed regressions where Run, Thread lifecycle, route, and primary-navigation state disagree during short transitions.

This issue group tracks five independent fixes:

- Prevent a rapid second Send click from stopping the Run it just started.
- Prevent archived Threads and rejected Run preparation from losing draft content.
- Preserve user-before-assistant ordering for the first Run of a promoted Thread Draft.
- Avoid a false Not Found notice while archiving the currently open Thread.
- Present Settings as the only current primary-navigation destination while it is open.

The Kimi Compact command-advertisement race is already covered by the existing Compact Thread Context issue group and is not duplicated here.
